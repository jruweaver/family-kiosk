# Family Command Center — self-hosted pages

These files are the kiosk (index.html) and the parents phone page (parents.html),
served from GitHub Pages instead of Google, so there is no Apps Script banner.
All data still lives in the Google Sheet; the pages talk to the Apps Script web app.

Upload every file in this folder to the root of a GitHub repository and turn on
Settings → Pages → Deploy from a branch → main / (root).

To update later: upload the new index.html / parents.html over the old ones.
